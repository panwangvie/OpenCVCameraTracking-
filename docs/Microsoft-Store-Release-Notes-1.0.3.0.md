# Microsoft Store Release Notes — 1.0.3.0

This document contains copy-ready release text for the Microsoft Store submission.

## 中文（中国）

### 此版本的新功能

- 新增非阻塞式 Microsoft Store 更新提醒：应用启动时以及持续运行期间每 20 分钟自动检查一次可用更新。
- 检测到新版本时，会在视频预览区域右上角显示简洁提示卡片，不会中断摄像头预览或识别工作。
- 用户可关闭当前版本的提示；当后续发布更高版本时，应用会再次提示更新。
- 优化主窗口左侧工具栏的布局与间距，减少不必要的滚动并改善小尺寸窗口下的可用性。

### 产品功能（可逐项填写）

1. 本地摄像头、RTSP/HTTP 网络视频流与本地视频文件预览。
2. 人脸与动物检测、目标跟踪，以及白名单识别和陌生目标提示。
3. 非阻塞式 Microsoft Store 更新提醒。

### 简短描述

CameraTracking 是一款基于 OpenCV 的桌面摄像头跟踪工具，支持本地摄像头和网络视频流的人脸、动物检测与白名单识别。

## English (United States)

### What's new in this release

- Added a non-blocking Microsoft Store update reminder. The app checks for updates at startup and every 20 minutes while it remains open.
- When an update is available, a compact card appears in the upper-right corner of the video preview without interrupting camera preview or recognition.
- Users can dismiss the reminder for the current version. The reminder is shown again when a later version becomes available.
- Refined the left-side toolbar layout and spacing to reduce unnecessary scrolling and improve usability in smaller windows.

### Product features (enter as separate items)

1. Preview local cameras, RTSP/HTTP network streams, and local video files.
2. Detect and track faces and animals, with whitelist recognition and unknown-target alerts.
3. Receive non-blocking Microsoft Store update reminders.

### Short description

CameraTracking is an OpenCV-based desktop camera tracking tool for face and animal detection, whitelist recognition, local cameras, and network video streams.
